# 波函数对比工作台

中文 Windows 桌面软件，用于比较 Bose-Hubbard 模型的多组 ITensors MPS/HDF5 波函数。Python/PyQt5 提供界面和 Matplotlib 交互曲线，Julia 负责物理量计算。

## 功能

- 手动设置十进制 U 网格；多组波函数可独立命名、设置线型 / 颜色 / 物理参数。
- 拖放或批量导入文件，先预览 U 对应关系，再调整文件顺序；不从文件名猜 U。
- 多选纠缠熵、纠缠谱、普通 / 标准化累积量、String / parity、能量、密度、关联、保真度等指标。
- 叠加曲线、差值图、数值表、可调整和滚动的图形区域，PNG/SVG/CSV 导出。
- 后台计算、停止与续算、逐项缓存、失败点记录；原始 HDF5 始终只读。
- 内置可搜索的“物理量计算说明”。详细定义见 [物理量定义.md](物理量定义.md)。

## 安装与启动

需要已有 Python、Julia 1.10 或更新版本，以及对应依赖。当前代码曾在 Python 3.6.5、PyQt 5.9.2、Matplotlib 2.2.2、Julia 1.10.10 的环境验证；新环境的依赖版本需要自行验证，仓库未附带运行时。

在软件目录打开终端，创建 Python 环境并安装依赖：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

准备 Julia 环境：

```powershell
julia --project=./julia -e "using Pkg; Pkg.instantiate()"
```

Julia 环境由 [Pkg](https://docs.julialang.org/en/v1/stdlib/Pkg/) 管理；新版 MPS 功能使用 [ITensorMPS](https://itensor.github.io/ITensorMPS.jl/stable/)。也可以复用已有的兼容 Julia 环境，不需要修改全局环境。

双击 **启动波函数对比.cmd**。启动入口优先使用本目录的 `.venv`，其次使用系统的 `pythonw` / `pyw` / `python`。也可以直接运行：

```powershell
.\.venv\Scripts\python.exe app.py
```

进入“运行环境”，填写 Julia 可执行文件的完整路径；如果使用仓库附带的 Julia 环境，把“Julia 项目目录”设为本目录下 `julia` 文件夹的完整路径。Python 路径修改在下次启动生效。不要把自己的环境配置提交到仓库。

## 一次比较

1. 输入 U 起点、终点和步长，生成 U 网格。
2. 选择波函数组，依次拖入文件，或点击“批量导入波函数”。可选择多个文件 / 添加单层文件夹，拖动或用上移下移调整顺序，再核对 U 预览。已有绑定跳过；超过空位时整批拒绝。
3. “组设置”修改名称、颜色、线型、备注，可覆盖公共物理参数、使用独立 U 网格。
4. 勾选物理量，点击“开始 / 继续计算”。文件内部参数冲突时修正对应关系。缺失或失败的点留空，曲线在缺点处断开。
5. 在“结果与导出”切换物理量 / 差值模式、显示的组。拖动图形与表格之间的分隔条调整占比；用“图形大小”或“适应窗口”控制画布，超出窗口时可滚动。
6. 顶部“物理量计算说明”可搜索各种指标的公式、区间和归一化定义；支持单图与总览导出。

示例 [examples/L20_MTBL_DMRG.json](examples/L20_MTBL_DMRG.json) 仅包含 U=1、1.5、2 和组名模板，文件绑定为空；载入后导入自己的波函数。仓库不含研究波函数、个人方案或已计算的研究结果。

## 数据、缓存与恢复

本地方案、运行配置、结果、日志和缓存放在 `data/`，该目录已由 `.gitignore` 排除。源文件路径只保存在本地方案里。保存 / 打开 JSON 方案可继续比较；“打开已有结果”可离线查看包含 `results.csv` 与方案快照的目录。

停止只作用于软件启动的 Julia 进程。已完成结果逐项保存，再次开始复用有效缓存并补算未完成部分。中心块熵采用两档精度检查，超过内存限额时报告失败，不自动放宽精度。缓存依据输入文件及物理设置、区间、精度和后端版本识别。

## 检查与范围

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

检查覆盖手动 U 网格、批量分配原子性、网格变更后的绑定保存、示例不含个人路径及后端文件完整性。它们不代表生产 MPS 的物理收敛测试。首版本地还执行过 36 个指标 × 4 种视图 × 2 轮的界面切换，以及导入 / 导出、异常保护和模拟画布 DPI 检查；随机闪退的唯一原因未被重现。

面向 OBC Boson MPS，默认数据集 `psi`，可手动指定。软件比较已保存状态，不运行 DMRG / MTBL 求解器，也不自动做标度拟合。
